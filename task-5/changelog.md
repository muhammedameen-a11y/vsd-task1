# Changelog

## v1.0.0 – Initial Release

### Added

* Implemented GPIO driver module.
* Added GPIO input initialization API.
* Added GPIO output initialization API.
* Added GPIO read functionality.
* Added GPIO output toggle functionality.

### Added

* Implemented UART driver module.
* Added UART initialization API.
* Added UART string transmission API.

### Added

* Implemented Timer driver module.
* Added timer initialization API.
* Added millisecond delay functionality.
* Added software tick counter support.

### Added

* Developed UART Software Oscilloscope application.
* Implemented GPIO sampling at fixed intervals.
* Implemented CSV-formatted UART streaming.
* Added configurable sampling interval.

### Hardware Verification

* Verified GPIO output generation on PD4.
* Verified GPIO input sampling on PD3.
* Verified UART communication at 115200 baud.
* Verified CSV output using PuTTY.
* Verified operation on VSDSquadron Mini hardware.
